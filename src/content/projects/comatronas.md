## Overview

Simple static website that gathers all the work of these two midwives, from both academic and professional life.

## Technologies

The page is made with **Wordpress**, having the main objective of being easy to maintain and add content to it from a _non-programmer_ point of view.

It's built using a combination of the included **Gutenberg** editor, **HTML**, **CSS** and **Javascript**. Using Wordpress mostly for its CMS capabilities while leaving the design aspects to the rest of technologies.

## Challenges and learning outcome

The main challenge I faced was the unfamiliarity with the block editor Wordpress uses by default. To be honest I still find it clumsy and unintuitive sometimes, but once I got the hang of it wasn't so hard to work with it.

I learned a lot about PHP and how the Wordpress API works, combining both native Wordpress blocks and custom HTML elements that interact directly with said API.
